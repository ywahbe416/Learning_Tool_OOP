# Data Structures

## Overview

A **data structure** is a way of organizing data in memory so it can be accessed and modified efficiently. Choosing the right one is often the difference between an O(n²) and O(n log n) solution.

| Structure | When to use | Key operations |
|---|---|---|
| Stack | LIFO ordering, undo, DFS | push/pop O(1) |
| Queue | FIFO ordering, BFS | enqueue/dequeue O(1) |
| Map | Key-value lookup | get/set O(1) avg |
| Set | Uniqueness, fast membership | has/add O(1) avg |
| Linked List | Frequent head insertions | insert-head O(1), search O(n) |
| BST | Sorted data, range queries | search/insert O(log n) |
| Heap | Repeated min/max access | peek O(1), insert/extract O(log n) |
| Graph | Relationships, paths | BFS/DFS O(V+E) |

---

## Stack

A **Stack** is LIFO — **Last In, First Out**. The most recently added item is the first to be removed. Think of a stack of plates: you add to the top, take from the top.

```javascript
class Stack {
  constructor() { this.items = []; }
  push(item)  { this.items.push(item); }
  pop()       { return this.items.pop(); }
  peek()      { return this.items[this.items.length - 1]; }
  isEmpty()   { return this.items.length === 0; }
}
```

**Real-world uses:**
- Undo / Ctrl+Z (most recent action on top)
- Browser back button history
- DFS (Depth-First Search)
- Evaluating expressions / parsing

**Time complexity:** push, pop, peek — all O(1)

---

## Queue

A **Queue** is FIFO — **First In, First Out**. The first item added is the first removed. Think of a line at a store.

```javascript
class Queue {
  constructor() { this.items = []; }
  enqueue(item) { this.items.push(item); }      // add to rear
  dequeue()     { return this.items.shift(); }   // remove from front
  peek()        { return this.items[0]; }
  isEmpty()     { return this.items.length === 0; }
}
```

**Note:** `shift()` is O(n) in JavaScript. For high-performance queues, use a linked-list or circular buffer implementation.

**Real-world uses:**
- Task scheduling, print queues
- BFS (Breadth-First Search)
- Circular wrap-around buffers (e.g., streaming)

## Map (HashMap)

A **Map** stores **key-value pairs**. Keys are unique — setting the same key twice overwrites the value. `HashMap` is the fastest implementation (O(1) average).

```javascript
const map = new Map();
map.set("alice", 95);
map.set("bob", 87);
map.get("alice");        // 95
map.has("carol");        // false
map.delete("bob");
map.size;                // 1

// Iteration
for (const [key, value] of map) {
  console.log(`${key}: ${value}`);
}
```

**Real-world uses:**
- Caching/memoization
- Frequency counting
- Two Sum (store seen values)
- Adjacency lists for graphs

**Time complexity:** get/set/has/delete — O(1) average, O(n) worst (hash collision)

---

## Set

A **Set** stores **unique elements only** — no duplicates. Membership check is O(1).

```javascript
const set = new Set([1, 2, 3, 2, 1]);
console.log(set.size);      // 3 — duplicates removed
set.add(4);
set.has(2);                 // true
set.delete(1);

// Set operations
const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);

const union        = new Set([...a, ...b]);        // {1,2,3,4}
const intersection = new Set([...a].filter(x => b.has(x))); // {2,3}
const difference   = new Set([...a].filter(x => !b.has(x))); // {1}
```

**Real-world uses:**
- Deduplication
- "Have I seen this?" checks in graph traversal
- Set math (union, intersect, difference)

## Linked List

Nodes linked by pointers. Each node holds a value and a reference to the next node. No contiguous memory — dynamic size.

```
[10 | →] → [20 | →] → [30 | null]
  head                    tail
```

| | Linked List | Array |
|---|---|---|
| Insert head | O(1) | O(n) |
| Insert tail | O(n)* | O(1)** |
| Search | O(n) | O(n) |
| Access by index | O(n) | O(1) |

*O(1) with tail pointer. **Amortized.

See the **Linked Lists** topic for the full deep-dive and interactive visualization.

## Tree / BST

A **tree** is a hierarchical structure. A **Binary Search Tree (BST)** enforces the property: **left child < parent < right child** at every node.

```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13
```

**BST rules:**
- All values in the **left subtree** < node value
- All values in the **right subtree** > node value
- This enables O(log n) search — at each node you halve the search space

**Key operations (balanced BST):**
- Search: O(log n)
- Insert: O(log n)
- Delete: O(log n)

**Traversals:**
- **In-order** (left → root → right): yields sorted output
- **Pre-order** (root → left → right): useful for copying the tree
- **Post-order** (left → right → root): useful for deletion

---

## Heap

A **Heap** is a complete binary tree where every parent satisfies the **heap property**:
- **Min-heap:** parent ≤ children → minimum is always at the root
- **Max-heap:** parent ≥ children → maximum is always at the root

```
Min-heap example:
        1
       / \
      3   5
     / \
    7   9
```

**Operations:**
- `peek()` — O(1): just look at root
- `insert()` — O(log n): add at bottom, bubble up
- `extractMin/Max()` — O(log n): remove root, reorganize

**Real-world uses:**
- Priority queues
- Dijkstra's shortest path
- Heap sort

---

## Graph

A **Graph** is a collection of **vertices (nodes)** connected by **edges**. Unlike trees, graphs can have cycles and multiple paths between nodes.

**Types:**
- **Directed**: edges have a direction (A → B)
- **Undirected**: edges go both ways (A — B)
- **Weighted**: edges have a cost/distance

```javascript
// Adjacency list representation
const graph = {
  A: ["B", "C"],
  B: ["A", "D"],
  C: ["A", "D"],
  D: ["B", "C"],
};
```

**BFS (Breadth-First Search)** — uses a **Queue**. Explores level by level. Finds shortest path in unweighted graphs.

**DFS (Depth-First Search)** — uses a **Stack** (or recursion). Explores as deep as possible before backtracking. Useful for cycle detection, topological sort.

```javascript
function bfs(graph, start) {
  const visited = new Set();
  const queue = [start];
  visited.add(start);

  while (queue.length > 0) {
    const node = queue.shift();
    console.log(node);
    for (const neighbor of graph[node]) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        queue.push(neighbor);
      }
    }
  }
}
```

**Time complexity:** O(V + E) — V vertices, E edges
