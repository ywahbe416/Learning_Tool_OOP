## Overview

A **data structure** is a way of organizing data in memory so it can be accessed and modified efficiently. Choosing the right one is often the difference between an O(n²) and O(n log n) solution.

| Structure | When to use | Key operations |
|---|---|---|
| Stack | LIFO ordering, undo, DFS | push/pop O(1) |
| Queue | FIFO ordering, BFS | enqueue/dequeue O(1) |
| HashMap | Key-value lookup | get/put O(1) avg |
| HashSet | Uniqueness, fast membership | contains/add O(1) avg |
| Linked List | Frequent head insertions | insert-head O(1), search O(n) |
| BST | Sorted data, range queries | search/insert O(log n) |
| Heap | Repeated min/max access | peek O(1), insert/extract O(log n) |
| Graph | Relationships, paths | BFS/DFS O(V+E) |

---

## Stack

A **Stack** is LIFO — **Last In, First Out**. The most recently added item is the first to be removed. Think of a stack of plates: you add to the top, take from the top.

```java
import java.util.ArrayList;

public class Stack<T> {
    private ArrayList<T> items = new ArrayList<>();

    public void push(T item)  { items.add(item); }
    public T pop()            { return items.remove(items.size() - 1); }
    public T peek()           { return items.get(items.size() - 1); }
    public boolean isEmpty()  { return items.isEmpty(); }
    public int size()         { return items.size(); }
}
```

**Real-world uses:**
- Undo / Ctrl+Z (most recent action on top)
- Browser back button history
- DFS (Depth-First Search)
- Evaluating expressions / parsing

**Time complexity:** push, pop, peek — all O(1)

## Queue

A **Queue** is FIFO — **First In, First Out**. The first item added is the first removed. Think of a line at a store.

```java
import java.util.ArrayList;

public class Queue<T> {
    private ArrayList<T> items = new ArrayList<>();

    public void enqueue(T item) { items.add(item); }           // add to rear
    public T dequeue()          { return items.remove(0); }    // remove from front
    public T peek()             { return items.get(0); }
    public boolean isEmpty()    { return items.isEmpty(); }
    public int size()           { return items.size(); }
}
```

**Note:** `remove(0)` on an ArrayList is O(n) — it shifts all elements. Java's built-in `ArrayDeque` is more efficient for production use.

**Real-world uses:**
- Task scheduling, print queues
- BFS (Breadth-First Search)
- Circular buffers (e.g., streaming)

## HashMap

A **HashMap** stores **key-value pairs**. Keys are unique — putting the same key twice overwrites the value. O(1) average for all operations.

```java
import java.util.HashMap;

HashMap<String, Integer> scores = new HashMap<>();
scores.put("alice", 95);
scores.put("bob", 87);
scores.get("alice");           // 95
scores.containsKey("carol");   // false
scores.remove("bob");
scores.size();                 // 1

// Iteration
for (String key : scores.keySet()) {
    System.out.println(key + ": " + scores.get(key));
}
```

**Real-world uses:**
- Caching/memoization
- Frequency counting
- Two Sum (store seen values)
- Adjacency lists for graphs

**Time complexity:** get/put/containsKey/remove — O(1) average, O(n) worst (hash collision)

## HashSet

A **HashSet** stores **unique elements only** — no duplicates. Membership check is O(1).

```java
import java.util.HashSet;

HashSet<Integer> set = new HashSet<>();
set.add(1); set.add(2); set.add(3); set.add(2); // duplicate ignored
System.out.println(set.size()); // 3
set.contains(2);                // true
set.remove(1);
```

**Real-world uses:**
- Deduplication
- "Have I seen this?" checks in graph traversal
- Fast membership testing

## Linked List

Nodes linked by pointers. Each node holds a value and a reference to the next node. No contiguous memory — dynamic size.

```
[10 | →] → [20 | →] → [30 | null]
  head                    tail
```

| | Linked List | Array |
|---|---|---|
| Insert head | O(1) | O(n) |
| Insert tail | O(n)* | O(1)** |
| Search | O(n) | O(n) |
| Access by index | O(n) | O(1) |

*O(1) with tail pointer. **Amortized.

See the **Linked Lists** topic for the full deep-dive and interactive visualization.

## Tree / BST

A **tree** is a hierarchical structure. A **Binary Search Tree (BST)** enforces the property: **left child < parent < right child** at every node.

```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13
```

**BST rules:**
- All values in the **left subtree** < node value
- All values in the **right subtree** > node value
- This enables O(log n) search — at each node you halve the search space

**Traversals:**
- **In-order** (left → root → right): yields sorted output
- **Pre-order** (root → left → right): useful for copying the tree
- **Post-order** (left → right → root): useful for deletion

## Graph

A **Graph** is a collection of **vertices (nodes)** connected by **edges**. Unlike trees, graphs can have cycles and multiple paths between nodes.

**Types:**
- **Directed**: edges have a direction (A → B)
- **Undirected**: edges go both ways (A — B)
- **Weighted**: edges have a cost/distance

```java
import java.util.*;

// Adjacency list representation
HashMap<String, List<String>> graph = new HashMap<>();
graph.put("A", Arrays.asList("B", "C"));
graph.put("B", Arrays.asList("A", "D"));
graph.put("C", Arrays.asList("A", "D"));
graph.put("D", Arrays.asList("B", "C"));
```

**BFS (Breadth-First Search)** — uses a **Queue**. Explores level by level. Finds shortest path in unweighted graphs.

**DFS (Depth-First Search)** — uses a **Stack** (or recursion). Explores as deep as possible before backtracking.

```java
public static void bfs(HashMap<String, List<String>> graph, String start) {
    HashSet<String> visited = new HashSet<>();
    Queue<String> queue = new LinkedList<>();
    queue.add(start);
    visited.add(start);

    while (!queue.isEmpty()) {
        String node = queue.poll();
        System.out.println(node);
        for (String neighbor : graph.get(node)) {
            if (!visited.contains(neighbor)) {
                visited.add(neighbor);
                queue.add(neighbor);
            }
        }
    }
}
```

**Time complexity:** O(V + E) — V vertices, E edges
