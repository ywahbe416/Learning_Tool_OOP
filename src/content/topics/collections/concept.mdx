## What is a Collection?

A **collection** is an object that **groups multiple elements** into a single unit. Java provides the **Java Collection Framework (JCF)** — a set of standardized interfaces and classes for storing and manipulating groups of objects.

---

## The Collection Hierarchy

```
Collection (interface)
├── List     → ordered, allows duplicates → ArrayList, LinkedList
├── Set      → unordered, no duplicates   → HashSet, TreeSet
└── Queue    → FIFO ordering              → LinkedList, PriorityQueue

Map (separate — not a Collection)
└── key-value pairs, no duplicate keys   → HashMap, TreeMap
```

| Type | Class | Characteristic |
|---|---|---|
| Ordered list | `ArrayList` | Index-based, duplicates allowed |
| Unique values | `HashSet` | No duplicates, O(1) lookup |
| Key-value pairs | `HashMap` | Fast O(1) lookup by key |
| Sorted map | `TreeMap` | Keys kept in sorted order |

## Collections Utility Class

`Collections` (with an 's') is a **utility class** with static helper methods for operating on collections.

| Method | What it does |
|---|---|
| `Collections.sort(list)` | Sorts in natural order |
| `Collections.sort(list, comparator)` | Sorts with custom comparator |
| `Collections.reverse(list)` | Reverses the list |
| `Collections.min(list)` | Returns smallest element |
| `Collections.max(list)` | Returns largest element |
| `Collections.frequency(list, val)` | Counts occurrences of val |

```java
import java.util.*;

ArrayList<Integer> nums = new ArrayList<>(Arrays.asList(3, 1, 4, 1, 5, 9, 2, 6));
Collections.sort(nums);    // [1, 1, 2, 3, 4, 5, 6, 9]
Collections.reverse(nums); // [9, 6, 5, 4, 3, 2, 1, 1]
```

## Comparable

The `Comparable<T>` interface defines the **natural ordering** of a class. Implement it when you want objects of your class to be sortable by `Collections.sort()`.

```java
class Student implements Comparable<Student> {
    String name;
    double gpa;

    public Student(String name, double gpa) {
        this.name = name;
        this.gpa = gpa;
    }

    @Override
    public int compareTo(Student other) {
        return Double.compare(other.gpa, this.gpa); // descending by GPA
    }
}

ArrayList<Student> students = new ArrayList<>();
students.add(new Student("Alice", 3.2));
students.add(new Student("Bob", 3.8));
students.add(new Student("Carol", 3.5));

Collections.sort(students); // Bob (3.8), Carol (3.5), Alice (3.2)
```

## compareTo()

`compareTo()` returns a number that determines order:

| Return value | Meaning |
|---|---|
| `< 0` (negative) | `this` comes **before** `other` |
| `0` | They are **equal** |
| `> 0` (positive) | `this` comes **after** `other` |

**Rules by type:**

| Type | How to implement |
|---|---|
| `int` | `Integer.compare(this.val, other.val)` |
| `double` | `Double.compare(this.val, other.val)` |
| `String` | `this.name.compareTo(other.name)` |
| Multi-field | Primary sort first; use secondary as tiebreaker |

```java
// Multi-field sort: GPA descending, then name ascending
@Override
public int compareTo(Student other) {
    if (Double.compare(other.gpa, this.gpa) != 0) {
        return Double.compare(other.gpa, this.gpa); // primary: GPA desc
    }
    return this.name.compareTo(other.name);         // tiebreaker: name asc
}
```

## Comparator

Use a **Comparator** when you want to sort by a different ordering than the natural one, or when you can't modify the class.

```java
import java.util.Comparator;

// Sort by name ascending (different from natural GPA order)
students.sort(Comparator.comparing(s -> s.name));

// Sort by GPA descending, then name ascending (tiebreaker)
students.sort((a, b) -> {
    if (Double.compare(b.gpa, a.gpa) != 0) return Double.compare(b.gpa, a.gpa);
    return a.name.compareTo(b.name);
});
```

**Note:** `list.sort()` in Java sorts **in-place**. To preserve the original, copy first:

```java
Student[] copy = students.toArray(new Student[0]);
Arrays.sort(copy, (a, b) -> Double.compare(b.gpa, a.gpa));
```
